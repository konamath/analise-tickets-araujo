# Bases locais

As planilhas originais não são distribuídas neste repositório público. Obtenha-as pelo canal autorizado da disciplina e coloque nesta pasta:

- `Tickets TI Fechados_2025.xlsx`, aba `Sheet1`.
- `Pesquisas de Satisfação_2025.xlsx`, aba `Sheet1`.
- `SLA por Serviço.xlsx`, aba `SLA por Serviços`.

O notebook reconhece diferenças de representação Unicode dos acentos nos nomes dos arquivos. O cruzamento dos valores de `Serviço` continua sendo exato.

Se as planilhas estiverem em outro local, preencha `PASTA_DADOS` na célula de configuração do notebook ou defina a variável de ambiente `ARAUJO_DADOS`.

As verificações de contagens e os hashes apresentados no notebook correspondem à extração fornecida para este trabalho. Uma nova extração pode exigir revisão dessas verificações.

Os arquivos desta pasta, exceto este guia, são ignorados pelo Git. Não envie as bases originais em commits, issues ou comentários públicos.
